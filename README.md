# Task 2 analysis code (COSC2669)

Code for Individual Task 2, Part 2. Run from the repository root, in this order:
01_evaluation.py, 02_learning_curves.py, 03_fairness.py, 04_privacy_security.py
(common.py is imported by all four).

Before running, create three folders: data/, results/ and figs/.
Put the two Task 1 datasets in data/ as superstore.csv and online_retail_full.csv.

The saved outputs of my run (eval.json, fairness.json, learning_curves.json,
privacy_security.json, the *_log.txt files and the two figures) are in the
repository root. Move them into results/ and figs/ to compare against a re-run.
